Lenguajes de programación

Un lenguaje de programación es el medio para expresar instrucciones que una computadora puede ejecutar. Cada lenguaje tiene su propia sintaxis y enfoque.

  • Existen lenguajes interpretados y compilados.
  • Algunos se usan para web, otros para datos o aplicaciones.
  • Python es ideal para aprender por su sintaxis clara.
Paradigmas de programación

Los paradigmas son estilos de programación que definen cómo se estructura el código. Algunos paradigmas comunes son imperativo, orientado a objetos y funcional.

  • Imperativo: instrucciones paso a paso.
  • Orientado a objetos: objetos con datos y comportamiento.
  • Funcional: funciones como elementos centrales.
Introducción a Python

Python es un lenguaje popular por su legibilidad y sintaxis sencilla. Es ideal para iniciar en programación y para desarrollar proyectos reales rápidamente.

edad = 20

if edad >= 18:
    print("Mayor de edad")
else:
    print("Menor de edad")
Operadores y estructuras

Los operadores realizan cálculos y comparaciones. Las estructuras condicionales y repetitivas permiten tomar decisiones y repetir acciones en el programa.

  • Operadores aritméticos: +, -, *, /.
  • Operadores relacionales: ==, !=, >, <.
  • Operadores lógicos: and, or, not.
Ejercicios
  1. Escribe un pseudocódigo que determine si un número es positivo, negativo o cero.
  2. Indica qué operador relacional usarías para comparar si una edad es mayor o igual a 18.
  3. Escribe un pequeño programa en Python que imprima los números del 1 al 5 usando un ciclo.
Soluciones

1. Inicio, leer número, si número > 0 entonces mostrar "positivo"; else si número < 0 mostrar "negativo"; else mostrar "cero"; fin.

2. El operador relacional es >=.

3. for i in range(1, 6): print(i)
