Hardware y Software
El hardware es lo físico: teclado, pantalla, memoria y procesador. El software es lo que corre en ese hardware: aplicaciones, juegos y sistemas.
  • Hardware: tangible y eléctrico.
  • Software: intangible y actualizable.

Ejemplo: el teclado es hardware y el procesador de texto es software.

¿Sabías que... el primer algoritmo para una máquina fue escrito por Ada Lovelace en 1843?

Resumen: El hardware es el cuerpo; el software es el cerebro.

Recursos: busca "hardware vs software" para intro rápida.

Modelos Von Neumann y Harvard
Von Neumann guarda datos e instrucciones juntos en una sola memoria. Harvard guarda cada uno en memorias distintas.
Von NeumannHarvard
Una sola memoriaDos memorias
Más simpleMás rápido en algunos casos

Ejemplo: Von Neumann es como usar un solo cuaderno para apuntes y recetas; Harvard es como usar dos cuadernos distintos.

¿Sabías que... muchos microcontroladores usan Harvard para trabajar más rápido?

Resumen: Von Neumann es común y fácil; Harvard es más seguro y rápido para ciertas máquinas.

Recursos: revisa comparativos de arquitectura para entender ejemplos prácticos.

Sistemas Operativos
El sistema operativo es el programa que controla la computadora. Administra programas, archivos y dispositivos como el teclado y la pantalla.
  • Organiza las aplicaciones.
  • Maneja la memoria.
  • Controla el hardware.

¿Sabías que... el primer sistema operativo práctico apareció en 1956 en una IBM?

Resumen: Sin sistema operativo no puedes usar la computadora de manera fácil.

Recursos: consulta resúmenes de funciones del SO para ejemplos.

Sistemas de Numeración
Los números se escriben con distintas bases: binario (2), decimal (10), octal (8) y hexadecimal (16).

¿Sabías que... las computadoras usan binario porque solo distinguen encendido y apagado?

Resumen: El binario es el lenguaje natural de las máquinas.

Recursos: videos o ejercicios de conversión para practicar.

Conversiones entre bases

Convertir es cambiar un número de una base a otra. Por ejemplo: 13 decimal = 1101 binario.

Ejemplo: 1011₂ = 13 decimal y = B hexadecimal.

Resumen: Las conversiones te ayudan a leer datos dentro de la computadora.

Nota: practica con los ejercicios al final para afianzar conversiones.

Aritmética Binaria

La aritmética binaria usa solo 0 y 1. Algunas reglas son:

  • 0 + 0 = 0
  • 0 + 1 = 1
  • 1 + 1 = 10

Ejemplo: 1010₂ + 0111₂ = 10001₂.

Resumen: La CPU suma y resta usando ceros y unos.

Recursos: busca "suma binaria" para practicar ejercicios interactivos.

Álgebra de Boole

El álgebra de Boole usa valores verdadero/falso (1/0). Sus operadores son AND, OR y NOT.

  • AND: verdadero solo si ambos son verdaderos.
  • OR: verdadero si al menos uno es verdadero.
  • NOT: invierte el valor.

Ejemplo: A=1, B=0 → A AND B=0, A OR B=1.

Resumen: Boole es la lógica que usan los circuitos para decidir.

Recursos: busca guías de álgebra de Boole y tablas de verdad para practicar.
