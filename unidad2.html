Algoritmos

Un algoritmo es un conjunto de instrucciones ordenadas que describen cómo resolver un problema paso a paso. Debe ser claro, finito y efectivo.

  • Entrada y salida definidas.
  • Pasos ordenados y no ambiguos.
  • Debe terminar después de un número finito de pasos.

Ejemplo: calcular el área de un cuadrado usando un algoritmo simple.

Diagramas de flujo

Los diagramas de flujo representan visualmente los pasos de un algoritmo usando símbolos conectados por flechas. Facilitan la comprensión y el diseño del proceso.

  • Inicio / fin.
  • Procesos y decisiones.
  • Entradas y salidas.

Ejemplo: diagrama de flujo que calcula el área de un cuadrado a partir del lado.

Pseudocódigo

El pseudocódigo usa instrucciones en lenguaje natural estructurado para describir un algoritmo. Es una guía para escribir el programa en un lenguaje real.

Inicio
Leer lado
area = lado × lado
Mostrar area
Fin

Es fácil de leer y se usa antes de escribir código real.

Modelado de problemas

Modelar un problema significa identificar qué datos se usan, cuáles son las operaciones necesarias y cuál es el resultado esperado. Esto ayuda a preparar soluciones más claras.

  • Analizar el problema.
  • Definir variables y condiciones.
  • Planificar la solución antes de programar.
Ejercicios
  1. Define los pasos para resolver el área de un rectángulo con pseudocódigo.
  2. Dibuja un diagrama de flujo para un algoritmo que determine si un número es par o impar.
  3. Identifica las entradas y salidas para un problema de conversión de unidades.
Soluciones

1. Inicio, leer base, leer altura, area = base × altura, mostrar area, fin.

2. Inicio → leer número → decisión par/impar → mostrar resultado → fin.

3. Entradas: valor y unidad; salida: valor convertido.
